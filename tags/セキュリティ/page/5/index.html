「なぜ、優秀なAIエージェントが、複雑な大規模開発において突如として不適切なコードを出力するのか」。この長年の疑問に対し、最新の論文『Constraint Decay: The Fragility of LLM Agents in Back End Code Generation』が極めて明快な学術的解答を提示しました。
