# 📊 X 情報分析・調査チェックリスト (X Information Analysis Points)

X（Twitter）から有益な情報を抽出し、`ProjectA` の各開発に役立てるために「どこに注目して調査すべきか」をまとめた、分析の着眼点リストです。

---

## 1. トレンド・需要の検知 (Trend & Demand)
「今、何が求められているか」を特定するための調査項目。

- [ ] **高初動キーワードの特定**: 特定のキーワードを含むポストが、投稿後数分以内でどれだけインプレッション（表示回数）を伸ばしているか。
- [ ] **ハッシュタグの「質」の推移**: 単なるトレンド入りではなく、そのタグを使っているユーザーが「一般人」か「業者」か「インフルエンサー」かの構成比率。
- [ ] **「比較」行動の抽出**: 「AとBどっちがいい？」「Aの代わりにBを使った」といったポスト。これは市場の勢力図や代替品の需要を浮き彫りにします。
- [ ] **疑問・質問のパターン**: 「〜のやり方がわからない」「〜のおすすめ教えて」という具体的な悩みのログ。

## 2. コンテンツ・表現の勝ちパターンの分析 (Content Patterns)
「どう伝えれば反応が取れるか」を特定するための調査項目。

- [ ] **インプレッション/エンゲージメント比率**: 閲覧数に対して「いいね」や「リポスト」が異常に高いポストの「画像枚数」や「1行目の文言」。
- [ ] **「さらに表示」のクリック誘発率**: Xの長文ポストにおいて、どの位置で文章が切られ、どのような引き（フック）があると続きが読まれているか。
- [ ] **リプライ欄の盛り上がり**: 議論が活発なポスト（Reply数が多いもの）の「問いかけ方」や「反論の余地の残し方」。
- [ ] **外部リンク（t.co）のクリック傾向**: どのドメイン（Amazon, note, Youtube等）が、今のXユーザーにとって最も「クリックすることへの抵抗感がない」か。

## 3. アカウント・競合調査 (Account & Competitor Research)
「誰が成功しているか」を特定するための調査項目。

- [ ] **伸びているアカウントの「運用初期」の挙動**: フォロワーが少ない状態で、どのようにして最初のバズを生んだか（リプライ回りか、トレンド便乗か）。
- [ ] **同一URLの投稿頻度と反応**: アフィリエイトリンクなどを繰り返し投稿しているアカウントが、どの程度の頻度なら凍結されず、かつ反応を維持できているか。
- [ ] **キャラクター（口調）の受容性**: 丁寧語、タメ口、あるいは特定の専門用語を多用する「オタク的」な口調、どのアカウントがファン（リピーター）を抱えているか。

## 4. プラットフォーム連携・移転の兆候 (Platform Drift)
「Xの外へ、情報がどう流れているか」を特定するための調査項目。

- [ ] **他SNSへの誘導パターンの成功例**: 「詳細はThreadsで」「続きはブログで」といった誘導が、どの程度の成功率（反応数）を持っているか。
- [ ] **スクリーンショットの拡散**: 別のSNS（Instagramやニュースサイト）で引用されているXのポストの共通点（情報の速報性か、ネタの面白さか）。

---

## 5. 本リストの活用方法
1. **調査開始時**: `X_Scruper` や `分析` ツールを動かす前に、本チェックリストから「今回の調査の主眼（例：疑問パターンの抽出）」を1つ選択する。
2. **分析中**: Ollama 等での解析時、これらの着眼点に沿ってデータを分類・スコアリングする。
3. **フィードバック**: 得られた知見は各プロジェクト（`X_affiliate` のAIプロンプト等）へ即座に反映する。
