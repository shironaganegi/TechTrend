WiFiは「通信」を卒業し「眼」になる。壁の向こうを視覚化する『wifi-densepose』の衝撃#

「壁の向こう側が見えたら」――そんな少年の日の妄想が、今、GitHub上のコードとなって結実した。

カメラを一切使わず、ただそこにあるWiFiの電波だけで人間の動きをトレースし、心拍数までも読み取る。嘘のような話だが、これはSF映画の予告ではない。オープンソースプロジェクト**『wifi-densepose』**が提示する、紛れもない現実だ。

もしあなたが「プライバシーを守りつつ、見守りを実現したい」という難題に頭を抱えているなら、この記事は福音になるだろう。ネットワークエンジニアからAI開発者まで、この「電波の再定義」がもたらす興奮を共有したい。

💡 WiFi信号という「見えない波紋」を読み解く#

これまで、WiFiは単なる情報の運び屋だった。しかし、この『wifi-densepose』は、WiFiを**「超高性能なレーダー」**へと変貌させる。

仕組みを直感的に理解するなら、静かな水面に石を投げ込んだ時の「波紋」を想像してほしい。人が動けば、WiFiという見えない波は乱れる。そのわずかな乱れ（CSI：Channel State Information）をAIが解析し、肉眼では見えないはずの「壁の向こう側の姿勢」を3Dメッシュで描き出すのだ。

なぜこれが変態的（最大級の賛辞だ）なほど凄いのか。ポイントは3つある。

🚀 常識を覆す4つの「眼」#

  • 「視ない」から守れるプライバシー: カメラを使わない。つまり「映されたくない場所」を映さずに済むのだ。浴室や寝室、更衣室。プライバシーの聖域でも、安全のための「監視」ではなく「見守り」が可能になる。
  • 壁を透視する「X線」の代替: WiFiの特性を利用し、壁や家具を透過。最大5メートルの深さまで「視る」ことができる。災害現場のガレキの下、誰かが息を潜めている。それを発見するのは、救助犬ではなくルーターかもしれない。
  • 触れずに感じるバイタル: 呼吸（6〜30回/分）や心拍（40〜120回/分）を非接触で計測。ウェアラブルデバイスの煩わしさから、人類を解放する第一歩だ。
  • Rustによる「超絶速」の処理: バックエンドはRust 1.85+で実装。54,000 fpsという、もはや人間の知覚を置き去りにするほどの圧倒的スピードでデータを捌き切る。

🛠️ 30秒で未来の片鱗に触れる#

「能書きはいい、動かしたい」という読者のために、Dockerを使ったクイックスタートが用意されている。

# 最新のイメージをプルして実行
docker pull ruvnet/wifi-densepose:latest
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
# ブラウザで http://localhost:3000 を開く

ただし、魔法を完全に使いこなすには相応の杖が必要だ。ESP32-S3などのCSI取得に対応したハードウェアを用意して初めて、この技術は真価を発揮する。普通のノートPCでは「そこに誰かがいる（RSSI）」という気配を感じるのが精一杯だが、それでもその感度の高さに驚くはずだ。

🏗️ 想像力が、この技術を「道具」に変える#

  1. 介護のパラダイムシフト: 「カメラで見張る」という抵抗感。それをゼロにしつつ、転倒や体調急変を察知する。これは優しさの実装だ。
  2. スマートホームの最終形: あなたがソファに座れば照明が落ち、ベッドに横たわれば空調が眠りに適した温度に変わる。センサーを意識させない「真のスマート」がここにある。
  3. 災害救助の切り札: 煙が充満し、視界ゼロの空間。救助隊のタブレットには、生存者の位置と心拍がリアルタイムで表示される。

✅ 尖った技術が抱える「光と影」#

もちろん、これが万能の魔法ではない。

  • メリット:
    • 画像データがそもそも存在しないため、漏洩リスクが物理的に低い。
    • 暗闇、煙、障害物を無視する「全天候型」の視覚。
  • 課題:
    • ESP32-S3等のハードウェア環境を整える「玄人向け」のハードル。
    • 部屋の構造による電波の跳ね返り（マルチパス）の影響を受けるため、丁寧な調整が不可欠。
