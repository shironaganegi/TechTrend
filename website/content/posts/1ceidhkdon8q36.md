# Claude Codeを「懐刀」に変える。スマホ一台でコードをねじ伏せるTelegram Botの衝撃

ターミナルに縛り付けられる日々は、もう終わりにしよう。

Anthropicが放った爆速AIエージェント「Claude Code」。その圧倒的なコード理解力と実行速度に酔いしれているエンジニアは多いはずだ。だが、一つだけ不満はないだろうか？ 「なぜ、この最強の相棒を、デスクを離れた瞬間に失わなければならないのか」と。

今回紹介するのは、そんなジレンマを鮮やかに解消する劇薬、「**claude-code-telegram**」だ。

これは単なるチャットボットではない。あなたのポケットの中に、24時間眠らない「シニア級エージェント」を常駐させるための召喚儀式なのだ。

## 自由への脱獄：なぜ今、スマホからの遠隔操作なのか？

エンジニアにとって、最高のアイデアが降りてくるのは決まってデスクの外だ。揺れる電車の中、あるいはカフェで最後の一口を飲み干した瞬間。そんな時、これまでは「帰宅してPCを開く」までその熱量を封印するしかなかった。

しかし、このBotを使えば話は変わる。
使い慣れたTelegramを開き、まるで同僚にメッセージを送るかのように指示を出す。それだけで、背後で動くClaude Codeがあなたのプロジェクトをスキャンし、バグを狩り、テストを回し、デプロイまで完結させてしまう。

これは「スマホでコーディングする」という苦行ではない。**「スマホから開発プロセスを指揮する」という、新しい特権だ。**

## 💡 ここが「白ネギ・テック」の唸ったポイント

- **対話がそのままプルリクになる**: 「あのファイルのバグを直して」――その一言が、緻密なコード修正へと変換される。もはやSSHログインの手間すら、過去の遺物だ。
- **GitHubとのシームレスな対話**: `gh`コマンドを裏側で自在に操る。クローンからIssue確認、プルリク作成まで、チャット画面が最強のコクピットに変わる。
- **自律的な「報告」の心地よさ**: Webhook連携により、CI/CDの結果をClaudeが要約して報告してくれる。あなたはただ、スマホに届く通知を「よし、承認だ」と眺めるだけでいい。
- **鉄壁のガード**: サンドボックス構造とユーザーID制限。この「猛獣」が、あなたの許可なく暴れ出すことはない。

## 🔧 爆速スタートアップガイド：数分で「魔法」を手に入れる

導入に身構える必要はない。Pythonが動く環境さえあれば、セットアップは一瞬で終わる。

### 1. 準備するもの
- Python 3.10以上
- [Claude Code CLI](https://claude.ai/code)（既にその手にあるはずだ）
- TelegramのBot Token（@BotFatherから数秒で取得できる）

### 2. インストールと設定

まずはリポジトリをクローンし、依存関係を整えよう。

```bash
git clone https://github.com/RichardAtCT/claude-code-telegram.git
cd claude-code-telegram
make dev
```

次に、`.env`ファイルを作成し、あなたの秘密の合言葉を書き込む。

```bash
TELEGRAM_BOT_TOKEN=あなたのトークン
APPROVED_DIRECTORY=/path/to/your/projects
ALLOWED_USERS=あなたのTelegramID
```

あとは `make run` を叩くだけ。これで、あなたのスマートフォンは、世界で最も賢い開発端末へと変貌を遂げる。
