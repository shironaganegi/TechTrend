## 💡 PentAGIとは？ なぜ、これまでの「AIツール」と一線を画すのか

PentAGI（Penetration testing Artificial General Intelligence）を一言で表すなら、**「24時間365日、文句ひとつ言わずに働き続けるサイバーセキュリティのプロフェッショナル」**だ。

かつて「AutoGPT」や「BabyAGI」に触れ、「構想は面白いが、実務では使い物にならない」と匙を投げたエンジニアも多いはずだ。しかし、PentAGIは違う。このツールは「セキュリティ」という明確な戦場に特化し、20種類以上のプロ用ツールを“自らの意志”で使い分ける。

汎用AIが「何でもできるが、何も極めていない」のに対し、PentAGIは「侵入する」という一点において、驚異的な執着を見せるのである。💾

## ✨ 震えるほどに研ぎ澄まされた、5つのコア・テクノロジー

1. **自ら戦術を組み立てる「自律型思考」**
   - ターゲットを与えれば、AIが自ら「まずはnmapで偵察し、次はあの脆弱性を突こう」とプランを練り、実行に移す。私たちはただ、その思考プロセスを眺めているだけでいい。
2. **20種類以上のプロツールを従える「指揮官」**
   - nmap、Metasploit、sqlmap……。ハッカーが長年愛用してきた武器を、AIが最適なタイミングで、最適なオプションと共に抜刀する。
3. **Neo4jによる「長期的記憶」の獲得**
   - ナレッジグラフ（Neo4j）を連携させることで、AIは過去の診断結果をグラフ構造で記憶する。単発の攻撃ではなく、点と点を結び、構造的に弱点を理解する知能を手に入れた。
4. **安全という名の檻「サンドボックス環境」**
   - すべての攻撃操作はDockerで隔離された環境内で行われる。あなたのホストマシンを汚すことなく、安全に“ハッキングの実験”を完結できるのだ。🛡️
5. **マルチLLM対応という「脳の換装」**
   - GPT-4、Claude 3、Gemini、そしてローカルで動くOllamaまで。状況やコストに合わせて、AIハッカーの「脳」を自由に入れ替えられる。

## 🔧 3つのコマンドで、AIハッカーを爆誕させる（Quick Start）

環境構築に時間をかけるのはナンセンスだ。Docker Composeさえあれば、あなたのPCは瞬時に最前線のラボへと変わる。

```bash
# 聖域への扉を開く
git clone https://github.com/vxcontrol/pentagi
cd pentagi

# 魂（APIキー）を吹き込む
cp .env.example .env
nano .env

# AIハッカーを起動！
docker-compose up -d
```

ブラウザを開けば、そこにはモダンなUIが広がっている。あなたはもう、ターミナルに張り付く必要はない。🔥
