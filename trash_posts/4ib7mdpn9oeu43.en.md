## 💡 What is Superpowers?

"Superpowers" is an **"agent skill framework"** specifically designed for AI agents like Claude Code and Cursor.

Its most defining feature is that it "prohibits" the AI from jumping straight into coding. By forcing it to follow the steps of a seasoned senior engineer—requirement definition, design, and Test-Driven Development (TDD)—it systematically eliminates the "half-baked code" that AI often produces. 🔧

## 🔥 4 Key Features That Make It Incredible

1.  **Rigorous Brainstorming (Design First)**
    Instead of immediate implementation, it starts with a deep dive into "what exactly needs to be built." It presents the design document section by section and refuses to move forward until the user provides explicit consent.

2.  **Sub-agent Driven Development (Parallel Execution)**
    The main agent acts as a "Commander," spawning "Workers (sub-agents)" for specific tasks. Watching it autonomously check task quality through a two-step verification process is nothing short of impressive.

3.  **Mandatory TDD (Test-Driven Development)**
    The AI manages the RED-GREEN-REFACTOR cycle on its own. It follows a Spartan rule: any code that fails the tests is deleted immediately! 💾

4.  **Clean Environments via Git Worktrees**
    It automatically creates isolated workspaces for tasks. This allows for safe experimentation without cluttering or "dirtying" your main branch.

## 🚀 When to Use It

- **Prototyping New Features**: When you have an idea but haven't fully fleshed out the design.
- **Refactoring**: When you want to safely modify legacy code that lacks test coverage.
- **Large-scale Implementations**: When you want to delegate heavy tasks that would normally take hours to an AI.

## ⚖️ Honest Impressions (Pros & Cons)

- **Pros**: Drastic improvement in code quality. Significant reduction in bugs caused by AI "assumptions." Above all, it genuinely feels like you're working with a professional.
- **Cons**: Because the initial overhead is high (design confirmations, etc.), it's not suited for quick, one-line fixes. You also need to be prepared for substantial Claude token consumption.
