### 例：OpenRouterという「賢い中継地点」
例えばOpenRouterは、多くの無料モデルを一つのインターフェースで提供してくれる。Pythonなら、数行のコードで「知能の断片」を呼び出すことが可能だ。

```python
import requests
import json

response = requests.post(
    url="https://openrouter.ai/api/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_FREE_API_KEY",
    },
    data=json.dumps({
        "model": "google/gemma-3-27b-it:free", # ここが「無料の扉」
        "messages": [{"role": "user", "content": "こんにちは！"}]
    })
)
print(response.json())
```
